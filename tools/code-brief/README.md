# Code指示書の型

チャットのAIに「決める役」、コードを書くAIに「作る役」を分けて使うための、貼って効く決まり2本です。決める側に貼る `chat_side.md` と、作る側の `CLAUDE.md` に貼る `claude_md_block.md` の2ファイルで、テンプレートや記入例はありません。

## 使い方

0. `chat_side.md` の本文を、チャットのAI（決める役）に貼る
1. `claude_md_block.md` の本文を、作業リポジトリの `CLAUDE.md` に貼る（無ければ作る）
2. 作業はチャットに頼み、出てきた指示書を読んでから、コードを書くAIに貼る
3. 返ってきた報告の5項目（変更ファイル一覧／前提確認の結果／［要確認］の充填と根拠／検査の結果／実物の所在）だけを見て、承認か修正を返す

## この型で守ろうとしていること

最終判断は人がする。決める側と作る側は互いに反証できる位置に置く。人が理解していないまま進めない。一気に進めない（止まる点を1つ置く）。決めたことは記録に残す。決まりの1行ごとの理由は、記事に書いています。

## ぼくの環境で確かめた結果（2026年9月11日）

Claude Code 2.1.263 で、別の作業フォルダに `claude_md_block.md` だけを `CLAUDE.md` として置き、指示書を2本渡しました。

- 「添付の原稿を使って README を直す」という指示書: 止まった。README は変更せず、原稿をファイル名で渡すよう求めてきた
- 公開日が「＜空欄＞」のままの指示書: 止まった。日付を推測で埋めず、［要確認］を残して報告した

結果は上の2件だけです。他の環境・他のAIでの動作は確かめていません。
