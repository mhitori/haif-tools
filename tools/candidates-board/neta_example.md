# ネタ帳（記入例）

思いついたら【在庫】に1行追記するだけ（30秒・体裁不要。書く行為そのものが承認）。
カードへの清書と棚の移動は、週に1回の棚卸しでやる。○×を決めるのは自分。

1行の書き方は自由: `- 日付 | 一言メモ`

プロダクト候補カードの項目（すべて「キー: 値」の字下げ行。空行でカードの終わり）:
- 出所: **必須**。自分の実務で実際につまずいたこと。空なら棚に入れない（一覧や思いつきからの発想は不可）
- 説明: **必須**。誰の何をどうするものか、1行
- 形: 指示書・テンプレート・ツール・教材・SaaS のどれか
- 層: 無料・有料
- 評価: 1問題1商品=○△×／記入例・実測の同梱=○△×／サポート負荷=低・中・高
- 枠該当: ○×（自分で決めた「出す商品の条件」に当てはまるか）
- 段階: 提案中/議論中/承認済み/着手/公開済み/見送り
- 解放予定: YYYY-MM または 未定
- 一体記事: その道具と一緒に出す記事の仮題
- 記事状況: 公開済み/下書き/未着手（手で更新する。ボードはこの欄を見て札の色を決める）
- 履歴: 日付＋一言（何行でも。積む）
