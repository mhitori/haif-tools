# セッション準備票の型

チャットのAI（決める側）は、前の日のことを覚えていません。セッションの最後にAIに
「準備票」を1枚書かせておき、翌朝の新しいチャットの先頭に貼る。人は説明し直しません。

## ファイル
- session_brief_template.md  準備票の型（5節）
- rules.md                   準備票を書く側の決まり4行（AIに貼る）
- example_2026-09-21.md      2026年9月21日の実物（外に出せない部分を削り、5節のうち3節を残したもの）

## 使い方
1. セッションの最後に、型（session_brief_template.md）と決まり（rules.md）を決める側のAIに貼り、準備票を書いてもらう
2. 書いてもらった準備票を、手元に保存する
3. 翌朝、新しいチャットを開いたら、準備票をそのまま先頭に貼る
4. 準備票の①（前提確認）の1行を作る側のAIに頼み、返ってきた報告を決める側に貼る

## 確かめた結果（2026-09-21）
前の晩に決める側のAIが書いた準備票を朝に1枚貼り、前の日のことを説明し直した回数は0回でした。この1日だけの実測です。
