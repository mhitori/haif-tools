# X投稿ボード v1（静的・HTML1枚）

A single HTML file that lists X (Twitter) post drafts as cards for copying and marking as posted; data is stored only in the browser.

X投稿の下書きをカードで並べ、本文をコピーしてXに貼り、投稿したら「投稿済みにする」で送る。それだけのツールです。
画面も動きも保存も、HTMLファイル1枚の中で完結します。サーバーも登録もありません。データはこのファイルを開いたブラウザの中（localStorage）にだけ保存されます。

制作記: [下書きの置き場──X投稿の管理を、HTML1枚で作った日](https://hitori-ai-factory.com/rensai/shitagaki-no-okiba/)（連載第2弾 第1話）

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックで開けます。自分のサイトの誰にも教えていないURLに置いてスマホのブックマークから開く、という使い方もできます。ただし下の「欠陥」を読んでから）
2. 「＋ 新しい投稿案」で見出し・種類・本文を入れて「棚に追加」
3. 出す順が決まったら「次に投稿へ」。投稿するときは「本文をコピー」→Xに貼る
4. 投稿したら「投稿済みにする」。カードは「投稿済み」に移り、投稿日が付きます
5. 「バックアップをコピー」で全カードを1つの文字列として書き出せます。メモ帳などに保存しておき、別のブラウザで開いたときに「バックアップから復元」に貼ると同じ状態になります
6. 「週次報告をコピー」は、投稿済みと残りの見出しを1つの文にまとめます

種類は 実況／報告／解説／問い の4つ。名前は `index.html` の `<select id="newType">` を書き換えれば変えられます。

## 欠陥2つ（作った本人が後で思い知ったもの）

1. **データは、そのブラウザの中にしかありません。** 別の端末や別のブラウザで開くと空です。バックアップの書き出しと復元は付けてありますが、自動では同期しません（連載第2弾 第1話・第2話）
2. **誰にも教えていないURLは、誰にも見えないURLではありません。** このファイルを公開サイトのどこかに置くと、URLを知らなくても見つかることがあります。自分の下書きを置くなら、ログインが要る場所に置くか、手元のファイルとして開いてください（第2話に、実際に見つかった記録があります）

この2つが理由で、ぼく自身はこのツールを8月27日に使うのをやめ、作り直しました。作り直した側は、4本目のツール [X自動投稿ボード一式](../x-autopost-board/) として公開しています。
