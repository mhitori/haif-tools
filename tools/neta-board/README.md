# ネタ帳ボード

ぼくが自分の候補管理に使っているものです（ぼくの内部では候補管理ボードと呼んでいます）。記入例は架空で、実測は記事のほうにあります。
制作記: [AIに反対されたが、半日で作った](https://hitori-ai-factory.com/jitsuroku/built-despite-ai-objection/)（実録 #04）

「作れそうなもの」を、出所つきのカードで1画面に並べるボードです。
ネタ帳（Markdown 1ファイル）を読んで、HTML 1枚を生成します。
いまも毎朝生成して使っているものを、そのまま置いています。

## 中身

| ファイル | 役割 |
|---|---|
| `neta_board.py` | 生成スクリプト。Python 3 の標準ライブラリだけで動きます（追加インストール・ネット接続なし） |
| `neta_example.md` | 記入例のネタ帳。カード5枚と、わざと書式を崩した行を入れてあり、ボードの表示状態が全部出ます |
| `neta_board_example.html` | 記入例から生成した見本のボード |
| `README.md` | このファイル |

## 使い方

```
python3 neta_board.py neta_example.md --today 2026-09-07 --example
```

`neta_example.md` と同じ場所に `candidates.html` ができるので、ブラウザで開きます。

自分のネタ帳で使うときは、ファイル名を渡すだけです。

```
python3 neta_board.py 自分のネタ帳.md -o 出力先.html
```

`--today` は基準日の指定です。省略すると今日になります。記入例は 2026-09 を前提に書いてあるので、日付を固定して描くと説明どおりの表示になります。
`--check` を付けると HTML を書かずに、件数と書式エラーだけ表示します。
`--example` を付けると、ボードの最上部に「これは記入例です」の帯を出します。同梱の見本HTMLはこの帯つきで生成しています。

## ネタ帳の書き方

書式は `neta_example.md` の冒頭にまとめてあります。要点は3つです。

1. 4つの棚を `## 【提案】` `## 【在庫】` `## 【済み】` `## 【没ネタ】` の見出しで分ける
2. 候補カードは `- 仮タイトル: 【プロダクト候補】名前` で始め、続く行を `  キー: 値` の字下げで書く。空行でカードの終わり
3. `出所`（自分の実務で実際につまずいたこと）と `説明`（誰の何をどうするものか）は必須

思いつきは【在庫】に `- 日付 | 一言` の1行で書けば足ります。カードへの清書は週1回の棚卸しでやります。
ぼくはこの清書をAIに任せ、○×だけ自分で決めています。

## ボードの見方

- **赤枠**: 出所なし。入口条件違反。出所を書くか、棚から外す
- **黄枠**: 説明なし。「誰の何をどうするものか」を1行で書く
- **NEW / 更新**: 記帳日、または履歴の最新日付が7日以内
- **解放計画レーン**: 当月から3ヶ月と「未定」の列に、解放予定の月ごとに札を並べる。札の色は `記事状況` 欄で決まる。緑は公開済み、赤枠は予定月を過ぎてまだ公開していないもの
- **書式エラー**: 読めなかった行を、消さずに一覧の上に出す
- **番号（#1〜）**: 提案、在庫、済み、没ネタの順の通し番号。○×を口頭やチャットで指定するときに使う

## このボードが守っていること

- 正本はネタ帳の `.md` だけ。ボードは読んで表示する側で、何も書き戻さない
- ○×（棚の移動と段階の変更）は人が決める。ボードは判定しない
- 読めないカードは消さずにエラーとして出す
- 「出所」が空のものは棚に入れない。一覧や思いつきから候補を作らないため

## ぼくが詰まったところ

このボードは1日で3版作りました。そのとき詰まった点を3つ書いておきます。

1. **最初の版は、何のプロダクトか分からなかった**。カードに評価の記号だけが並んで、説明が読めなかった。「説明」を必須にして、空なら黄枠で警告するようにしたのが2版目です
2. **解放予定の自動判定は、自分のサイトの構造に依存していた**。記事が公開済みかどうかを自分のサイトのファイルから読んでいたので、配布版では `記事状況` を手で書く方式に変えました
3. **書式を間違えたカードが、静かに消えていた**。パーサが読めない行を捨てていたので、候補が1枚減っても気づかない。読めない行は「書式エラー」欄に出す方式にしました

## 記入例について

`neta_example.md` の5枚は、家計簿CSVの整形、読書メモの整理、請求書PDFの命名の3系統で作った架空の例です。
ぼく自身の候補カードは、まだ公開していない内部の判断を含むので、そのまま載せていません。
出所・評価・履歴の書きぶりは、ぼくの実物と同じ密度にしてあります。
