# AGENTS.md

## このプロジェクト

- これは、家計簿の CSV を月ごとに集計する Python のスクリプトです
- 返事は日本語で書く

## コードを書くとき

- Python は 3.12 を使う
- 外部のライブラリを足さない
- 関数には型ヒントを付ける
- 金額は整数（円）で扱う

## 検査

- コードを変えたら pytest を走らせる
- テストが落ちたままコミットしない

## ファイル

- data/ の CSV を書き換えない
- 出力は out/ に書く

## 記録

- コミットメッセージは日本語で書く
- 1つのコミットには1つの変更だけを入れる
