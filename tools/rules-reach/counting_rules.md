# 数え方（分母と、行ごとの判定の線）

照らしの前に、この11項目を決めておきます。線は、配布元が決めた線です。変えたときは記録の「迷った所」に書き、前の回の記録は直しません。

「（2026-10-14 に足した）」の印の文は、2026年10月14日の実測で、元の線だけでは決められなかった所に足したものです（example/ の照らしの記入例の最後の「迷った所」と対応しています）。

## 分母

1. 分母に数えるのは、決まりのファイルの「決まりの行」。箇条の1行は1行と数える。地の文なら1文を1行と数える。プロジェクトの説明の1行（「これは〜です」）も数える
2. 数えないのは、題（# の行）・見出し（## の行）・空行・フォルダやファイルの構成の説明（「src/ はコードの置き場」のような、決まりではない説明の行）
3. 自動のメモ（Claude Code の MEMORY.md の目次）が届く場面では、その目次の行も分母に足す。届いたかは書き出しに出たかで見る
   - （2026-10-14 に足した）自動のメモは、目次の行が書き出しに出たときだけ届いたとする。ファイルの名前だけが出て、中身は無いと書かれたときは届かなかったとし、その添え書きを①の答えの欄に写す
4. 長い行は、句が2つ以上ある行。句は、読点で区切られ、それぞれに述語がある部分。行ごとに、照らしの前に句に分けて書いておく（example/ の行の一覧の右の列）

## 行ごとの判定

5. 判定は、元の行ごとに4つのどれか
   - そのまま: 行の中の要素を1つも省かずに書いた。語順や言い回しの違いはそのまま
   - 言い換え: 要素を1つでも省いたか変えたが、指示の向きは同じ。「等」「必ず」「など」の省略も言い換え。長い行は、どの句を省いたか（前半・後半）を書く
   - 欠け: その行に当たる項目が書き出しに無い
   - 取り違え: 指示の向きが逆か、別の中身にした
   - 1行を2項目に分けて書いた・2行を1項目にまとめて書いたときは、元の行ごとに判定する
   - （2026-10-14 に足した）要素は、句・条件・数・名前・例の5つ。修飾の語（「端数の」「先に」など）だけを省いたときは、5つが残っていればそのままとし、省いた語を記録の「省いた・変えた要素」の欄に書く。ただし、指示の強さや範囲を変える語（「必ず」「絶対に」「等」「など」「すべて」）の省略は、上の行のとおり言い換えとする
   - （2026-10-14 に足した）句の述語を省いても、同じ行のほかの述語で意味が通り、句の要素が残っていれば、言い回しの違いとしてそのまま
   - （2026-10-14 に足した）説明の行（「これは〜です」）を、指示の形（「〜として扱う」など）に変えて書いたときは、言い換えとする。変えた要素は「文の種類（説明→指示）」と書く
   - （2026-10-14 に足した）書き出しの見出しの文言は項目に数えない。行の中身が見出しにしか出ていないときも欠けとする
   - （2026-10-14 に足した）行に当てるかは、書き出しの見出しではなく中身で決める。中身の要素がそろわない項目は、見出しが決まりのファイルでも外から届いたものに数える。見出しが別でも要素がそろえば行に当て、そのことを欄に書く
6. 一致は「そのまま」と「言い換え」の合計

## 分母の外

7. 書き出しの項目のうち、どの行にも当たらないものは、分母に入れず「決まりのファイルの外から届いたもの」として別に数え、中身の要点を書く（私用の値は伏せる）。問いの文から来た項目（「ツールを使わずに答える」など、問いの文をそのまま決まりとして書いたもの）は、外から届いたものとも分けて「問いから来たもの」として別に数える
   - （2026-10-14 に足した）問いから来たもの・外から届いたものは、書き出しの項目の数で数える（問いの文の行の数では数えない）
   - （2026-10-14 に足した）書き出しの中の、決まりではない注（「省いた」「全部ではない」など）は項目に数えず、外から届いたものの表の下に要点を書く。省いたと書かれていれば、外から届いたものの数は下限として扱う
8. サブエージェントの係の定義（Claude Code では .claude/agents/ の本文）は分母に入れず、「定義の行のうち書き出しに出た数」として別に数える。ぼくの記録では、係の定義はファイル名なしで、その係のいちばん最初の指示として届いていた

## 記録の扱い

9. 答えは、決まりのファイルを開く前に写して固定する。あとから直さない・要約しない
10. 決まりのファイルに行を足したら分母を数え直す。前の回の分母は直さない
11. 問いの文を変えたら、記録の「問いの形」の欄に、前の回と変えた所を書く
