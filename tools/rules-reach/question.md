# 問い（セッションの最初に貼る）

新しいセッションの最初の発言として、下の枠の3行をそのまま貼ります。前に挨拶や説明を打ちません。

```
ツールを使わずに、この返事の中で答えてください。
① この会話の最初に自動で読み込まれたファイル（ファイル名だけ）
② ファイルを開かずに、いま守っている決まりを全部（出どころごとに見出し・1行1項目）
```

## 貼るときに守ること

- 答えが出るまで、そのセッションで決まりのファイルを開かない・見せない・「読んで」と言わない
- 答えは最初の1回のものを使う。返事の作り直し・問いの書き直しと再送をしない（答えが2つになると、どちらが最初か分からなくなる）
- 比べたい版や場面ごとに、それぞれ新しいセッションで聞く。1つのセッションで続けて聞かない
- 返事の途中にツールを使った表示（ファイルを読んだ行など）が出たら、止めずに最後まで待ち、どのファイルかを記録に書く。許可を求められたら許可しない

## 頭の1行について

1行目の「ツールを使わずに、この返事の中で答えてください。」は、①に答えるために AI がフォルダの中を見に行く（決まりのファイルを開く）と、書き出しの意味が無くなるので入れています。2026年10月14日の実測では、2つの答えとも、この1行を問いから来た決まりとして書き出しに入れました（見出しは「あなたの今回の指示」と「ユーザーのこのメッセージから」）。記録では「問いから来たもの」として別に数えます（counting_rules.md の 7）。

## 任意の3問目（起動時の知らせ）

前の回では、次の3問目を足した形でも聞きました。前の回の文面は一字一句は残っていません。下は、記録に残る問いの形（起動時の知らせの原文）から書いた文です。

```
③ この会話の最初に差し込まれた知らせ（起動時の知らせ）の原文
```

- 決まりのファイルの中身が、会話のどこに入って届いたかを見るための問いです
- ぼくの記録では、③の答えにメールアドレスとホームフォルダのパスが入っていました。記録に置く前に伏せてください
- 問いの数を変えた回は、記録の「問いの形」の欄に書きます（counting_rules.md の 11）

## 問いを変えたら

問いの文を1字でも変えたら、記録の「問いの形」の欄に、前の回と変えた所を書きます。前の回の記録は直しません。
